## The entry

> Forty minutes, nine people, and the meeting's only decision was who would send the email.

The joke is the meeting's own output: forty minutes of nine people's time produced exactly one decision — and that decision was to send an email, the very thing the meeting existed to replace. The line never says "this could have been an email"; it lets the punchline arrive on the last word instead. Anyone who has sat through a meeting that ended with an action item to write the email the meeting was supposed to be will recognise it instantly.

## How it works

`main.ts` writes the single line (89 characters, no trailing newline) to `/output/entry.txt`. It is deterministic: no network, no randomness, no files read from outside the repository. Before writing, it checks the line against the competition's gate (1–200 characters, not only whitespace) and refuses to write an invalid line.

```sh
node main.ts
cat /output/entry.txt
```
